# المهندس وائل محمد عراقي | Portfolio المهني المتخصص
### Technical Office Manager & Project Controls Engineer (Planning & Cost Control)

موقع ويب بورتفوليو تفاعلي عالي الاحترافية، مصمم بالكامل بنظام (HTML5 / CSS3 / Vanilla JS) لعرض الخبرات الهندسية، والمشاريع الكبرى في مصر والمملكة العربية السعودية، ومنظومة التحكم في التكاليف وإدارة القيمة المكتسبة (EVM)، ولوحات Power BI، والأتمتة الذكية عبر n8n وذكاء الأعمال.

---

## 🌟 مميزات وخصائص الموقع

1. **ثنائي اللغة بالكامل (Bilingual System - AR / EN):**
   - يدعم التبديل اللحظي بين العربية (`dir="rtl"`) والإنجليزية (`dir="ltr"`) بضغطة زر واحدة.
   - تمت صياغة المحتوى بمصطلحات هندسية معتمدة ومطابقة لمعايير معاهد إدارة المشروعات العالمية (**PMI & AACE**).

2. **قسم متخصص وحصري لهندسة التحكم في التكاليف (Cost Control Hub):**
   - **محاكي تفاعلي حي لإدارة القيمة المكتسبة (Interactive EVM Simulator):** يتيح للزوار ومسؤولي التوظيف والعملاء تعديل قيم المشروع (BAC, Planned %, Earned %, AC) عبر أشرطة تمرير تفاعلية، مع حساب لحظي لمؤشرات:
     - $PV$, $EV$, $AC$
     - $CPI$, $SPI$
     - $EAC$, $ETC$, $VAC$
     - تشخيص فني ذكي وديناميكي (Healthy, Cost Overrun, Behind Schedule, Dual Variance).
   - **دورة حوكمة التكاليف المتكاملة (6-Step Cost Governance Cycle):** من دراسة المقايسة وبناء ميزانية الصفر (Budget Zero) إلى الإغلاق المالي وحماية هامش الربح التشغيلي.
   - **عرض أدلة عملية حية (Applied Dashboards):**
     - مخطط علاقات البيانات **Star-Schema Data Model** المنفذ في Power BI.
     - لوحة مراقبة هوالك المواد الموقعية وتحليل المخزون (Material Wastage & Store Tracking).
     - تحليل تفكيك أسعار البنود التفصيلية (Unit Rate Breakdown vs Budget).
     - لوحة تطور هامش الربح الإجمالي (Gross Profit Margin Evolution).
     - منحنيات التدفق النقدي التراكمي ومدرج العمالة (Cash Flow S-Curve & Manpower Histogram).

3. **سجل المشاريع الكبرى (Major Landmark Projects):**
   - **مشروعات المستشفيات والرعاية الصحية بالمملكة العربية السعودية (KSA):**
     - مجمع عيادات ومستشفى الأورام التخصصية - الرياض (بقيمة 35 مليون ريال سعودي).
     - قسم الأورام - مستشفى الملك سعود التخصصي بالطائف.
   - **مشروعات الفنادق والمنتجعات الكبرى في مصر:**
     - فندق دار الدفاع الجوي (تيبا روز) بالعاصمة الإدارية الجديدة (بقيمة 450 مليون جنيه مصري - إدارة تنفيذ كاملة وصور درون جوية موثقة).
     - فندق دار الدفاع الجوي بالغردقة (بقيمة 100 مليون جنيه مصري).
     - مبنى الجيم والإسطبل الأولمبي للخيول بالعاصمة الإدارية (بقيمة 170 مليون جنيه مصري).
   - **محفظة إدارة مشروعات متزامنة (Enterprise Multi-Project Portfolio):**
     - شركة دليل الهدى الإنشائية (العلمين، سوهاج، المنوفية، ماونتن فيو التجمع الخامس بقيمة إجمالية 370 مليون جنيه مصري).
   - **مشروعات الطرق والكباري والبنية التحتية:**
     - شركة النيل العامة للطرق: طريق دمياط - عزبة البرج والطريق الخرساني بميناء دمياط.
   - **نظام تصفية تفاعلي (Interactive Filters):** للفرز الفوري بين المستشفيات، الفنادق، المحافظ، والطرق.

4. **قسم التحول الرقمي والأتمتة (AI & n8n Automation Edge):**
   - مخطط تدفق تفاعلي يوضح كيفية توظيف الذكاء الاصطناعي وأتمتة n8n في تحويل رسائل وصور الواتساب والموقع غير المنظمة إلى تقارير موثقة ومعتمدة بضغطة زر واحدة (Human-in-the-Loop) ومزامنتها لحظياً مع Power BI.

5. **المصفوفة التقنية والأدوات الهندسية (Tech Stack):**
   - بريمافيرا P6، مايكروسوفت بروجكت، EVM، أوتوكاد، ريفيت، باور بي آي (DAX)، إكسل متقدم، n8n، بايثون، وأنظمة الذكاء الاصطناعي.

6. **معرض وسائط تفاعلي (Interactive Lightbox Modal):**
   - إمكانية تكبير وفحص مخططات الشوب دروينج الطبية، وصور الدرون الجوية لفندق العاصمة الإدارية، ولوحات الـ Power BI بدقة عالية.

7. **مطابقة معايير السرية للنشر العام (NDA Compliant):**
   - تم حجب وتأمين أي أرقام هواتف خاصة أو بيانات شخصية حساسة.
   - تم توفير نموذج تواصل مهني مباشر وروابط رسمية للبريد واللينكد إن، مع إبراز الجاهزية التامة للانتقال للعمل بالمملكة العربية السعودية والمشروعات الدولية.

## 🚀 كيفية فتح وتشغيل الموقع

### الطريقة الأولى (المباشرة):
- انقر نقراً مزدوجاً (Double Click) على ملف `index.html` ليفتح مباشرة في أي متصفح (Chrome, Edge, Safari, Firefox).

### الطريقة الثانية (عبر خادم محلي Local Server):
إذا كنت تستخدم Python، يمكنك فتح موجه الأوامر في مجلد المشروع وتشغيل:
```bash
python -m http.server 8080
```
ثم فتح المتصفح على: `http://localhost:8080`
